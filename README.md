🧠 About the Project

JARVIS is a Python-based voice assistant designed to interact with users through voice commands.

The assistant listens to spoken commands, processes them, performs the requested action, and responds using text-to-speech.

This project demonstrates the integration of Python, Speech Recognition, Text-to-Speech, Web Automation, Wikipedia Search, YouTube Integration, and System Automation.

🚀 Installation & Setup

1️⃣ Clone the Repository

git clone https://github.com/viveksharma-cs/voice_assistant.git

2️⃣ Navigate to the Project

cd voice_assistant

3️⃣ Create a Virtual Environment

python -m venv .venv

4️⃣ Activate the Virtual Environment

🪟 Windows

.venv\Scripts\activate

🐧 Linux / macOS

source .venv/bin/activate

5️⃣ Install Dependencies

pip install SpeechRecognition pyttsx3 wikipedia pywhatkit

6️⃣ Run JARVIS

python voice_assistant.py
